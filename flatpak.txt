for run the flatpack need :

flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

Then you can enter the development environment:

flatpak run --command=bash org.gnome.Sdk//46

Inside it you should have:

pkg-config --modversion gtk4
meson --version
ninja --version

--------> 

One important detail: when you are inside the SDK shell, your project folder from /home/kkaratsi may not automatically be visible. If it is not, start the SDK with your home mounted:

flatpak run --command=bash --filesystem=home org.gnome.Sdk//46
